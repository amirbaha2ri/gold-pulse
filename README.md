# Gold Pulse

افزونهٔ Chrome برای نمایش و پایش قیمت یک گرم طلای ۱۸ عیار از وب‌سایت [میلی](https://milli.gold/).

> **Repository name:** `gold-pulse`  
> **Version:** `2.3.2`

## امکانات

- دریافت قیمت طلا بدون نیاز به بازکردن وب‌سایت
- تبدیل قیمت دریافتی از ریال به تومان
- نمایش اختیاری قیمت روی Badge افزونه
- به‌روزرسانی خودکار در بازه‌های زیر:
  - ۳۰ ثانیه
  - ۱ دقیقه
  - ۵ دقیقه
  - ۱۰ دقیقه
  - ۳۰ دقیقه
- امکان تعیین حداقل و حداکثر قیمت
- هشدار از طریق Badge، اعلان ویندوز یا هر دو
- قرمزشدن Badge هنگام خروج قیمت از محدودهٔ تعیین‌شده
- بازگشت خودکار رنگ Badge به حالت عادی پس از ورود قیمت به محدوده
- نمایش پیام موفقیت و جمع‌شدن تنظیمات پس از ذخیره

## نمایش قیمت روی Badge

Badge چهار رقم اول قیمتِ تومان را بدون گردکردن نمایش می‌دهد و برای خوانایی میان آن‌ها کاما قرار می‌گیرد.

برای مثال:

```text
231,470,000 ریال → 23,147,000 تومان → Badge: 23,14
```

## نصب افزونه

1. پوشهٔ پروژه را دانلود یا Extract کنید.
2. در Chrome وارد صفحهٔ `chrome://extensions` شوید.
3. گزینهٔ **Developer mode** را فعال کنید.
4. روی **Load unpacked** کلیک کنید.
5. پوشهٔ `V2` را انتخاب کنید.

پس از ایجاد هر تغییر در فایل‌های افزونه، در همین صفحه روی دکمهٔ **Reload** کلیک کنید.

## نحوهٔ استفاده

1. روی آیکن افزونه کلیک کنید.
2. در صورت نیاز، نمایش قیمت روی Badge را فعال کنید.
3. بازهٔ به‌روزرسانی خودکار را انتخاب کنید.
4. حداقل و حداکثر قیمت را برحسب **تومان** وارد کنید.
5. نوع هشدار را انتخاب کرده و روی **ذخیره تنظیمات** کلیک کنید.

## دسترسی‌های مورد استفاده

- `storage`: نگهداری قیمت و تنظیمات افزونه
- `alarms`: اجرای به‌روزرسانی خودکار
- `notifications`: نمایش اعلان قیمت
- دسترسی به `https://milli.gold/*`: دریافت قیمت طلا
