Gold Pulse - Chrome Extension
Version 2.4.0

Features:
- Reads the 1 gram 18K gold price from tgju.org without opening the website.
- Displays and stores prices in toman (the source website reports rial).
- Optional price display on the extension badge.
- Automatic refresh:
  Off / 30 sec / 1 min / 5 min / 10 min / 30 min
- Minimum and maximum price alerts.
- Alert mode:
  Badge / Windows notification / Both
- The badge shows the first four toman price digits without rounding (for
  example, 23,147,000 is shown as 23,14) and turns red while the price is
  outside the configured minimum/maximum range.
- The settings panel collapses and shows a confirmation after a successful save.
- A help button below the settings reveals the developer's GitHub and LinkedIn links.
- The question-mark button opens the creator's GitHub profile.

Installation:
1. Extract the ZIP.
2. Open chrome://extensions
3. Enable Developer mode.
4. Click Load unpacked.
5. Select this extracted folder.

Data source:
https://www.tgju.org/profile/geram18
